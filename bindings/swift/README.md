# AgentSDK — Swift binding

Generated by `cargo run -p agent-ffigen` (UniFFI 0.28.3) from the `agent-sdk`
cdylib. The high-level API is in `Sources/AgentSDK/agent_sdk.swift`; the
low-level FFI module lives in `Sources/agent_sdkFFI/`.

## Wire the native library

Build the Rust cdylib, then make `libagent_sdk` discoverable to the linker:

```bash
cargo build -p agent-sdk
# macOS:
cp target/debug/libagent_sdk.dylib /usr/local/lib/   # or link via -L
# Linux:
cp target/debug/libagent_sdk.so /usr/local/lib/
```

## Usage

```swift
import AgentSDK

let agent = createAgent(AgentConfig(session: "default",
                                     agentName: "agent",
                                     sandboxProvider: "docker",
                                     model: "gpt-4o-mini"))
let reply = agent.run("hello")
let session = agent.session()
session.memorize(key: "fact1", value: "the moon is cheese")
print(session.recall(key: "fact1") ?? "")
```
