# AriaAgent — Swift binding

Generated by `cargo run -p aria-agent-ffigen` (UniFFI 0.28.3) from the `ariacompute-agent`
cdylib. The high-level API is in `Sources/AriaAgent/aria_agent_ffi.swift`; the
low-level FFI module lives in `Sources/aria_agent_ffi/`.

## Wire the native library

Build the Rust cdylib, then make `libaria-agent_ffi` discoverable to the linker:

```bash
cargo build -p ariacompute-agent
# macOS:
cp target/debug/libaria-agent_ffi.dylib /usr/local/lib/   # or link via -L
# Linux:
cp target/debug/libaria-agent_ffi.so /usr/local/lib/
```

## Usage

```swift
import AriaAgent

let agent = createAgent(AgentConfig(session: "default",
                                     agentName: "agent",
                                     sandboxProvider: "docker",
                                     model: "gpt-4o-mini"))
let reply = agent.run("hello")
let session = agent.session()
session.memorize(key: "fact1", value: "the moon is cheese")
print(session.recall(key: "fact1") ?? "")
```
