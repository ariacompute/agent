# AgentSDK — Kotlin / Android binding

Generated by `cargo run -p agent-ffigen` (UniFFI 0.28.3) from the `agent-sdk`
cdylib. The high-level API is in
`src/main/kotlin/com/agent/uniffi/agent_sdk/agent_sdk.kt`.

## Wire the native library

Build the Rust cdylib for each target ABI, then place the artifacts so the
runtime can load them:

```bash
# example: cross-compile for Android arm64
cargo build -p agent-sdk --target aarch64-linux-android --release
mkdir -p src/main/jniLibs/arm64-v8a
cp ../target/aarch64-linux-android/release/libagent_sdk.so \
   src/main/jniLibs/arm64-v8a/libagent_sdk.so
```

`libagent_sdk.so` is loaded via `System.loadLibrary("agent_sdk")` by the
generated bindings.

## Usage

```kotlin
import com.agent.uniffi.agent_sdk.*

fun main() {
    val agent = createAgent(AgentConfig("default", "agent", "docker", "gpt-4o-mini"))
    val reply = agent.run("hello")
    val session = agent.session()
    session.memorize("fact1", "the moon is cheese")
    println(session.recall("fact1"))
}
```
